# Reading financial statements

You are given passages from draft financial statements and, sometimes, last year's signed statements.

## What to check

- **Tie-out.** A figure on the face of the statements should agree to the trial balance or a note. When asked whether it does, quote the line in the statements and the line it should agree to.
- **Comparatives.** Last year's column in the draft should equal last year's signed statements. Quote both where you can see both.
- **Casting.** Sub-totals and totals shown should follow from the lines above them. Report a break only when the lines are all in front of you.
- **Disclosure.** For the item asked about, is the note there (accounting policy, related parties, directors' loans, going concern, post balance sheet events, commitments)? A note that is absent is `missing`; a note you were not shown is `unclear`.
- **Consistency.** Names, dates, year end and company number should be the same throughout.

## Citing

Cite the line or sentence that carries the figure or the disclosure. For a missing note there is nothing to cite: say which note and why it is expected.

## Do not

- Judge whether an accounting treatment is correct beyond what the Direction Note asks.
- Treat a draft watermark, a blank signature block or a placeholder such as "XX" as an error unless asked: note it as `low`.
